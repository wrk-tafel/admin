Ein Passkey im Gerät gehört zu dem Gerät, auf dem er eingerichtet wurde; ein Sicherheitsschlüssel (z. B. ein YubiKey) kommt dagegen mit Ihnen und funktioniert an jedem PC, an dem Sie ihn anstecken oder auflegen - auch an einem gemeinsam genutzten.
