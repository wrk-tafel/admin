Neue E-Mail-Adresse bestätigen

@switch (state()) { @case ('done') {
Die neue E-Mail-Adresse ist gespeichert. An die bisherige Adresse wurde ein Hinweis gesendet.
} @case ('invalidLink') {
Dieser Link ist ungültig oder abgelaufen. Ein Link ist nur eine Stunde gültig, kann nur einmal verwendet werden und gilt nicht mehr, wenn die Adresse inzwischen anders geändert wurde. Ändern Sie die Adresse bei Bedarf unter "Mein Konto" erneut.
} @case ('failed') {
Die Bestätigung konnte nicht gesendet werden. Bitte versuchen Sie es in einem Moment erneut.
} @default {

Für Ihr Benutzerkonto wurde eine neue E-Mail-Adresse angegeben. Mit "Bestätigen" wird sie übernommen - an sie gehen dann Systembenachrichtigungen, Codes der Zwei-Faktor-Authentifizierung und "Passwort vergessen?". Haben Sie keine Änderung veranlasst, bestätigen Sie nicht.

} }
