Titel Anliegen

Die Anfrage wird per E-Mail versandt. Mitgesendet werden automatisch technische Infos zur Fehlersuche: Benutzername, aktuelle Seite, Browser, die letzten Fehlermeldungen dieser Sitzung und ein Screenshot der Seite. Bei einem Anliegen zu einem Kunden bitte die Kundennummer statt Name verwenden und vor dem Öffnen dieses Formulars von der Kundenseite wegnavigieren, falls deren Inhalt nicht mitgeschickt werden soll.
