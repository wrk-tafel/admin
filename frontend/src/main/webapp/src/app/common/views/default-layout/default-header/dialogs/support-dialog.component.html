Die Anfrage wird per E-Mail an das Support-Team versandt. Mitgesendet werden:

  • Titel und Anliegen
  • technische Infos zur Fehlersuche: Benutzername, aktuelle Seite, Browser und die letzten Fehlermeldungen dieser Sitzung
  • wenn oben ausgewählt, ein Screenshot der aktuellen Seite - auf einer Kundenseite also auch deren Inhalt

Lesen können die Anfrage nur die Empfänger:innen der Support-Adresse.
